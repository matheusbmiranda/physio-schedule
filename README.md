# Physio Schedule

Sistema Full-Stack para gerenciamento de pacientes e gestão de agenda de fisioterapeutas, desenvolvido com Spring Boot, Angular e MongoDB.

## Tecnologias

### Backend

- Java 21
- Spring Boot 4
- Spring Data MongoDB
- Maven
- Lombok
- Bean Validation

### Frontend

- Angular
- TypeScript
- Angular Material

### Banco de Dados

- MongoDB Atlas

## Arquitetura

O projeto é dividido em dois módulos:

```text
physio-schedule

backend/

frontend/
```
